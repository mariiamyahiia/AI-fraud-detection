# AI Fraud Detection System

End-to-end Machine Learning pipeline for credit card fraud detection.

## Architecture
- **Member 1 (Current)**: Data Understanding, Cleaning, EDA, Stratified Split & Scaling Pipeline.
- **Member 2**: Feature Engineering & Class Imbalance (SMOTE / Class Weights).
- **Member 3**: Model Training (Logistic Regression, Random Forest, XGBoost) & Evaluation (PR-AUC).
- **Member 4**: Hyperparameter Optimization, Explainability (SHAP) & Streamlit App.
